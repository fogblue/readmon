개인정보 처리방침

리드몬(Readmon)

시행일: 2026-08-14 최종 수정일: 2026-08-21

요약

리드몬은 회원가입이 없고, 계정을 만들지 않으며, 이용자의 개인정보를 서버로 수집하지 않습니다. 개발자는 이용자가 무슨 책을 읽는지, 무엇을 들었는지 알 수 없습니다.

읽고 있는 책과 읽은 위치는 이용자의 기기 안에만 있습니다. 낭독(음성 합성)도 기기 안에서 처리되며, 책의 문장이나 만들어진 음성이 외부로 전송되지 않습니다.

기기 밖으로 무언가가 나가는 경우는 이용자가 직접 그 기능을 설정했을 때뿐 입니다 — 원격 서재 연결, 클라우드 저장소 연결, iCloud 동기화, 그리고 AI 목소리를 쓰기 위한 최초 1회 모델 내려받기입니다. 각각을 아래에 그대로 적습니다.

1. 개발자가 수집하는 개인정보

없습니다.

리드몬은 다음을 하지 않습니다.

  • 회원가입·로그인·계정 생성
  • 이용 기록, 청취 기록, 읽은 책 목록의 서버 전송
  • 광고 식별자(IDFA) 수집 및 맞춤형 광고
  • 이용자 추적(App Tracking Transparency 상 tracking)
  • 제3자 분석 도구(Google Analytics, Firebase, Sentry, Crashlytics 등) 탑재
  • 크래시 리포트의 개발자 서버 전송

앱에 포함된 외부 라이브러리는 압축 파일 처리와 음성 합성을 위한 것 (ZIPFoundation, Unrar, SWCompression, FluidAudio) 네 가지뿐이며, 이들 중 이용자 정보를 수집하는 것은 없습니다.

App Store를 통한 구매·환불 처리는 Apple이 수행하며, 개발자는 구매 여부만 Apple로부터 전달받습니다. 개발자는 이용자의 이름·이메일·결제수단 정보를 받지 않으며 보관하지도 않습니다.

3. 낭독(음성 합성)은 기기 안에서 이루어집니다

AI 목소리 낭독은 이용자의 기기 안에서 실행됩니다. iOS에 내장된 음성 합성이 기기에서 동작하는 것과 같은 방식입니다.

  • 책의 문장이 서버로 전송되지 않습니다. 낭독할 텍스트는 기기를 떠나지 않습니다.
  • 만들어진 음성이 서버로 전송되지 않습니다. 음성은 기기에서 생성되어 기기에서 재생됩니다.
  • 낭독 중에는 네트워크 연결이 필요하지 않습니다. 비행기 모드에서도 동작합니다.
  • PDF의 글자 인식(스캔한 책을 읽어 주는 기능)도 Apple이 제공하는 기기 내 문자 인식 기능을 사용하며, 이미지나 인식된 글자가 외부로 전송되지 않습니다.

무료 "시스템 음성"을 선택한 경우에는 iOS에 내장된 음성 합성 기능을 사용합니다. 이때도 앱은 책의 문장을 개발자나 제3자에게 보내지 않습니다. 다만 그 기능은 Apple이 제공하는 것이므로, 음성 데이터의 처리와 추가 음성 내려받기에는 Apple의 정책이 적용됩니다.

다만 한 가지, 최초 1회의 내려받기가 있습니다. AI 목소리를 처음 사용할 때 음성 합성 모델 파일을 내려받아야 하며, 이때 huggingface.co에 접속합니다. 이때 전송되는 것은 어떤 파일을 달라는 요청뿐 이며, 이용자의 책·문장·개인정보는 전송되지 않습니다. 내려받기가 끝나면 이후의 낭독에는 네트워크가 필요하지 않습니다. 자세한 내용은 4항에 적습니다.

4. AI 목소리 모델 내려받기

AI 목소리를 사용하려면 음성 합성 모델을 기기에 내려받아야 합니다. 이 파일은 앱 설치 파일에 포함되어 있지 않습니다(앱 용량을 줄이고, AI 목소리를 쓰지 않는 이용자가 받지 않아도 되게 하기 위함입니다).

  • 접속처: huggingface.co (Hugging Face, Inc.가 운영하는 모델 배포 서비스)
  • 시점: 이용자가 앱에서 내려받기를 직접 시작했을 때만. 자동으로 받지 않습니다. 한 번 받은 뒤에는 파일이 기기에 있는 한 다시 접속하지 않습니다 — 새 버전이 있는지 확인하러 접속하는 동작은 없습니다. 파일이 삭제되거나 손상된 경우에만 다시 받습니다.
  • 전송되는 정보: 파일 요청에 필요한 통상적인 통신 정보(IP 주소 등 접속 시 기술적으로 수반되는 정보)뿐입니다. 이용자의 책·문장·읽기 기록·기기 식별자를 개발자나 Hugging Face에 보내지 않습니다.
  • 개발자는 이 접속을 기록하거나 열람하지 않습니다. 개발자의 서버를 거치지 않고 기기가 직접 내려받습니다.

Hugging Face의 개인정보 처리에 대해서는 해당 사업자의 방침이 적용됩니다.

5. 원격 서재·클라우드 저장소 (이용자가 설정했을 때만)

이용자가 외부 서비스에서 책을 받아오도록 설정하면, 그 서비스와 통신이 발생합니다. 설정하지 않으면 이 통신은 전혀 일어나지 않습니다.

5-1. 이용자가 주소를 직접 입력하는 경우 — Calibre-Web, OPDS, WebDAV

  • 접속처를 이용자가 정합니다. 개발자가 지정한 서버가 없습니다.
  • 이용자가 입력한 아이디와 비밀번호가 그 서버로 전송됩니다(해당 서버에 로그인하기 위함입니다). 개발자에게는 전송되지 않습니다.
  • 책을 검색하면 검색어가 그 서버로 전송됩니다.
  • 통신이 암호화되는지는 이용자가 입력한 주소에 달려 있습니다. https://가 아닌 주소를 입력하면 통신이 암호화되지 않습니다.

5-2. 계정으로 연결하는 경우 — Dropbox, Google Drive, OneDrive

  • 각 서비스의 공식 인증 방식(OAuth)으로 연결합니다. 비밀번호는 앱이 보지 않으며, 각 서비스의 로그인 화면에서 직접 입력합니다.
  • 접속처는 각 서비스의 공식 주소로 고정되어 있습니다.
  • Google Drive는 읽기 전용 권한(drive.readonly)만 요청합니다.
  • 연결을 해제하면 저장된 인증 정보가 기기에서 삭제됩니다.

Google Drive에서 무엇을 가져와 무엇을 하는지 그대로 적습니다.

구분 내용
접근(access)이용자가 앱에서 폴더를 열어 볼 때, 그 폴더에 있는 항목의 이름·종류·크기·수정 시각을 읽습니다. 이용자가 책을 고르면 그 파일의 내용을 내려받습니다
사용(use)오직 앱 화면에 서재 목록을 그리고, 고른 책을 열어 읽고 듣게 하기 위해서만 사용합니다
저장(store)내려받은 책 파일은 이용자의 기기 안에만 저장됩니다. 인증 토큰은 iOS 키체인에 저장됩니다
공유(share)누구에게도 전송하지 않습니다. 개발자의 서버로 보내지 않고, 제3자에게 제공하지 않으며, 광고·분석·프로파일링·인공지능 모델 학습에 사용하지 않습니다

개발자는 이용자의 Google Drive 데이터를 열람할 수 없습니다. 앱과 Google 사이의 통신은 이용자의 기기에서 직접 이루어지며 개발자의 서버를 거치지 않습니다.

5-4. Google 사용자 데이터의 제한적 사용 (Limited Use)

리드몬이 Google Workspace API(Google Drive)에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(Google API Services User Data Policy)을 따르며, 여기에는 제한적 사용 요건(Limited Use requirements)이 포함됩니다.

Readmon's use of information received from Google Workspace APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

구체적으로 리드몬은 다음을 하지 않습니다.

  • Google 사용자 데이터를 광고 목적으로 사용하거나 광고 플랫폼에 전송하는 것
  • Google 사용자 데이터를 데이터 브로커·정보 판매업자에게 제공하는 것
  • Google 사용자 데이터를 신용 평가나 대출 심사 목적으로 사용하는 것
  • Google 사용자 데이터로 인공지능·기계학습 모델을 학습시키는 것
  • 사람이 Google 사용자 데이터를 읽는 것 (개발자는 열람 수단 자체가 없습니다)

6. iCloud 동기화 (이용자가 켰을 때만)

이용자가 iCloud 동기화를 켜면 다음이 Apple의 iCloud에 저장됩니다.

  • 읽은 위치·진행률 — 이용자 본인의 iCloud 비공개 데이터베이스에 저장됩니다. 책의 본문은 올라가지 않습니다.
  • 이용자가 직접 올린 책 파일 — iCloud Drive의 앱 폴더에 저장됩니다. 파일 앱에서 직접 확인하고 삭제할 수 있습니다.

이 정보는 Apple의 iCloud 계정 안에 있으며 개발자는 접근할 수 없습니다. iCloud에 저장된 정보의 처리에는 Apple의 개인정보 처리방침이 적용됩니다.

동기화를 끄거나 iCloud에서 파일을 삭제하면 저장이 중단·삭제됩니다.

7. 만 14세 미만 아동의 개인정보

리드몬은 만 14세 미만 아동을 대상으로 하지 않으며, 연령을 포함해 어떠한 개인정보도 수집하지 않으므로 아동의 개인정보를 수집하는 일이 발생하지 않습니다.

8. 이용자의 권리

개발자가 이용자의 개인정보를 보유하고 있지 않으므로, 개발자에게 열람·정정·삭제를 요청할 대상이 없습니다. 기기에 저장된 정보는 이용자가 직접 통제합니다.

  • 앱 삭제 — 기기에 저장된 모든 정보가 함께 삭제됩니다
  • 원격 서재·클라우드 연결 해제 — 저장된 접속 정보가 삭제됩니다
  • iCloud 동기화 끄기 — iCloud 저장이 중단됩니다
  • 내려받은 AI 목소리 모델 삭제 — 앱 안에서 삭제할 수 있습니다
